## 1. 주 독자

포트폴리오나 이력서의 링크로 이 저장소를 여는 면접관이다. 면접관은 첫 화면을 짧게 훑고 더 읽을지 정한다. 받아서 돌려 볼 개발자는 둘째 독자이고, 그 몫은 기준 12의 실행 절에서 참고로만 본다.
