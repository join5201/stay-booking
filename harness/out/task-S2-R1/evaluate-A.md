## 4. 평가자 지시 원문

너는 이 문서가 만들어진 논의를 보지 못했고 볼 필요도 없다. 문서에 적힌 것만으로 판정한다. 금지: 파일 수정, 문체나 표현 지적, 문서에 없는 내용을 추측으로 채우기. 판단이 안 서면 확인필요로 남긴다.

심각도는 셋이다. 치명은 요구사항이나 불변식이 깨지는 것, 보통은 문서가 불완전하거나 규칙과 어긋나지만 치명적이지는 않은 것, 확인필요는 문서만으로 판단할 수 없는 것이다. 확인필요 등급을 반드시 유지한다. 문맥 부족에서 오는 오판을 치명으로 올리면 멀쩡한 결정을 뒤집게 된다.

## 6. 출력

eval-criteria-ddd.md 4절 스키마를 그대로 쓴다. 열을 바꾸지 않는다.

```
## 판정 요약
치명 N / 보통 N / 확인필요 N

## 상세
| 심각도 | 위치 | 위반 축 | 문제 | 문서 내 근거 | 수정 제안 |

## 요구사항 역추적표
| 요구사항 | 문서에서 대응되는 항목 | 커버 여부 |
```

원본 스키마 뒤에 보조 표를 붙인다. 열은 원본 번호, 지적 ID, 심각도, 위반 기준 넷이다. 판정 요약의 등급별 수와 이 표의 등급별 수가 같아야 한다. G2가 이 표에서 심각도를 읽어 결정표와 대조하므로, 표가 없거나 수가 어긋나면 리포트가 잘린 것으로 처리된다.

지적 ID 규약은 S2-R1-A-{원본 번호 2자리}다. 예로 첫 지적은 S2-R1-A-01이다.

보조 표 뒤에 다음을 적는다. 실제 읽은 파일과 버전, 적용한 축, 시작과 종료 시각과 실제 사용 시간 또는 미측정, 미확인 범위와 추가로 필요한 입력.

지적 수 0과 검증 완료를 구분한다. 리포트가 불완전하거나 필수 확인을 하지 못한 경우 통과로 기록하지 않는다.
