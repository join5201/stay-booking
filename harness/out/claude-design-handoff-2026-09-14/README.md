| 파일 | 역할 | 넘기는 방법 |
|---|---|---|
| prompt.md | Claude Design에 시키는 말. 무엇을, 어떤 순서로, 어떤 형태로 낼지와 하지 말 것 | 구분선 아래를 첫 메시지로 붙인다 |
