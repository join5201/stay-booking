# reviews/

무엇이 들어가는가: Codex 평가 리포트 원문이다. 요약하거나 편집하지 않는다.

왜 필요한가: 리포트를 요약하면서 자기 결정에 불리한 지적을 빼는 것이 금지 사항이다(harness-prompts/eval-criteria-ddd.md 8절). 원문을 남겨야 결정표와 대조할 수 있다.

파일명 규약: reviews/task-S{Step}-R{라운드}-{A 또는 B}.md
예: reviews/task-S9-R1-A.md, reviews/task-S9-R1-B.md

A와 B는 다른 새 작업에서 나온 리포트다. 한 파일에 합치지 않는다. 지적 ID는 S{Step}-R{라운드}-{A 또는 B}-{원본 번호 2자리}.
