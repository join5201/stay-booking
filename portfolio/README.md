# portfolio

최초 작성: 2026-09-16
최종 갱신: 2026-09-16 (신설)

이 저장소의 작업을 재료로 만든 포트폴리오와 이력서 블록이다. 평가 입력이 되지 않고 하네스의 라운드에 들어가지 않는다. 기준은 생각등대 채널의 면접관 기준을 정리한 dev-resume-lighthouse 스킬이고, 기준점 판단은 2026-09-16 사용자 승인이다.

| 파일 | 무엇 |
|---|---|
| portfolio-draft-v1.md | 포트폴리오 초안. 문제 해결 제목 셋과 제목마다 아키텍처, 데이터 플로우, 시퀀스 도식과 상세 세 줄 |
| resume-stay-booking-block.md | 이력서 Projects에 넣을 stay-booking 블록 일곱 줄. 포트폴리오 제목 셋이 이 블록의 줄에서 온다 |

규칙 셋.

| 규칙 | 왜 |
|---|---|
| [채울 것]은 지어내지 않는다. 수치가 없으면 측정 방법을 같이 적는다 | 근거 없는 문장은 면접에서 무너진다 |
| 도식은 mermaid 펜스로 둔다 | GitHub와 노션 코드 블록이 그대로 그린다. 그림 파일을 따로 관리하지 않는다 |
| 판이 바뀌면 파일 이름의 v를 올리고 앞 판은 남긴다 | 어느 판을 어디에 냈는지 되짚을 수 있어야 한다 |

내부 용어를 쓰지 않는다. 하네스는 AI 개발 워크플로우, 작업 계약은 계획 승인 게이트, 평가 A와 B는 독립 리뷰어 둘, G1과 G2는 형식 검사와 결정 대조 검사로 쓴다. 면접관은 이 저장소의 규칙 파일을 읽지 않은 사람이다.
