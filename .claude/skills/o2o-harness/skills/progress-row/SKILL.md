# 기록 행

최초 작성: 2026-09-21
최종 갱신: 2026-09-21 (신설. 이슈 189)

왜 이 스킬이 필요한가: 행 규칙이 progress.md 머리와 CLAUDE.md 4절과 5-1절과 harness/state/README.md에 나뉘어 있고, 서울 시각을 구하는 법은 어디에도 없어 세션 개인 메모리에만 있었다. 값 칸에 설명을 덧붙인 사고가 세 번 났다. 정본은 각 파일 머리이고 여기는 더할 때의 순서와 실수 목록이다.

## 1. 순서

| 순서 | 하는 일 | 근거 |
|---|---|---|
| 1 | 시각. Git Bash는 date -u -d '+9 hours' '+%Y-%m-%d %H:%M'(TZ를 무시하므로 UTC에 9시간을 더한다). PowerShell은 Get-Date -Format 'yyyy-MM-dd HH:mm' | 서울 시각. 세션 메모리에서 옮김 |
| 2 | 칸 수를 파일 머리에서 센다. progress.md 열두 칸, troubleshooting.md 여섯 칸, knowledge.md 일곱 칸 | 각 파일 머리 |
| 3 | 행 하나를 파일 끝에 더한다. 기존 행은 고치지 않는다. 틀린 행은 새 행의 대체 칸에 그 행의 날짜시각을 적는다 | 추가 전용. merge=union |
| 4 | 머리글의 최종 갱신 줄은 건드리지 않는다 | union으로 그 줄이 둘이 된다 |
| 5 | 더한 행의 칸 수를 센다. 파이프 기호가 값에 들어가면 역슬래시로 이스케이프한다 | 넘친 칸은 마크다운이 버린다 |
| 6 | node harness/tools/check.mjs union .gitattributes | 같은 행 둘, 옛 판 접두, 칸 수 어긋남 |
| 7 | 행은 이유 하나에 커밋 하나. 메시지 앞자리는 chore(state) | CLAUDE.md 4-1 |

## 2. progress.md 열두 칸

| 칸 | 값 규칙 |
|---|---|
| 날짜시각 | YYYY-MM-DD HH:MM. 순서가 아니라 이 칸으로 읽는다 |
| Task | task-S{Step} 또는 task-S{Step}-{기능키}. 준비 단계는 H0부터 H6. 하네스 작업은 그 이름 |
| 라운드 | R1 또는 R2. 아니면 해당 없음 |
| 단계 | 계약, 생성, G1, 평가A, 평가B, 결정, G2, 반영, 최종 중 하나. 준비 단계는 준비 |
| 결과 | pending, drafted, reviewed, applied, done, halted 중 하나 뒤에 한 줄 요약. done은 사용자 승인 행에서만(N5). 사용자 발언과 시각을 요약에 넣는다 |
| 실패 원인 | 실패했을 때만. 아니면 없음. 재요청 프롬프트의 원천이다(HR3) |
| 교훈 | 다음에 달리 할 것. 없으면 없음. 두 번 나오면 07 v3 DO NOT에 한 줄 |
| 다음 작업 | 다음 행이 무엇이어야 하는가. 누가 하는지도 |
| 실제 시간 | 실측값 또는 미측정 |
| 증거 | 돌린 명령과 그 출력, 또는 파일 경로. 없으면 없음. 비면 그 행은 주장이지 기록이 아니다 |
| 안 해 본 것 | 떠올렸으나 안 해 본 방법. 없으면 없음 |
| 대체 | 이 행이 바로잡는 앞 행의 날짜시각. 없으면 없음 |

## 3. 자주 나는 실수

| 실수 | 왜 안 되나 |
|---|---|
| 값 칸에 사람이 읽기 좋은 한마디를 덧붙인다 | 검사기가 읽는 칸은 값만 담는 자리다. 세 번 났다(CLAUDE.md 5-1) |
| 파일의 마지막 행을 이번 Task의 마지막 행으로 읽는다 | 세션이 여럿이면 마지막 행은 남의 Task다 |
| done 행에 병합 커밋 해시를 적으려고 병합 뒤 기록 브랜치를 연다 | 병합 해시 대신 PR 번호를 적는다. 병합 전이면 그 브랜치 마지막 커밋, 병합 뒤면 다음 작업 브랜치 첫 커밋(CLAUDE.md 4-1 7단계) |
| 결과 파일이 생겼으니 통과라고 적는다 | 파일의 존재가 아니라 안의 숫자를 읽는다. 증거 칸에 그 숫자를 적는다 |
| 옛 행의 빈 뒤 세 칸을 채운다 | 옛 행의 뒤 세 칸은 빈 것이 아니라 없는 것이다 |
| 두 세션이 같은 자리에 행을 더한 뒤 union 검사를 건너뛴다 | union은 충돌 대신 두 판을 다 남긴다. 네 번 났다 |

## 4. 다른 두 파일

| 파일 | 칸 | 언제 |
|---|---|---|
| troubleshooting.md | 날짜시각, 단계 또는 Task, 증상, 원인, 조치, 상태 | 막힌 것 전부. 해결 못 한 것도 미해결로 |
| knowledge.md | 날짜, 항목, 알게 된 것, 출처, 승격 위치, 난이도, 체크 | 두 번째로 난 원인의 승격, 공식 문서로 확인한 키와 명령, 확인 못 한 것의 [추측] |
